PROJETO SIREN — SIMULADOR HTML

Arquivos:
- index.html
- styles.css
- script.js

Funcionamento:
- "Adicionar 250 ml" registra água normalmente.
- É possível informar outra quantidade.
- Ao informar exatamente 180 ml e confirmar, o sistema:
  1. adiciona 180 ml à hidratação para manter a aparência comum;
  2. aciona silenciosamente a central simulada;
  3. exibe um aviso no telefone do contato de confiança.
- Nenhum aviso de emergência aparece no app de água.

IMPORTANTE:
Este é um protótipo didático. Nenhum serviço real, autoridade, telefone ou API externa é acionado.

Como abrir:
1. Mantenha index.html, styles.css e script.js na mesma pasta.
2. Abra index.html no navegador.
3. Para apresentar, prefira notebook/desktop para ver os três painéis ao mesmo tempo.
