# SIREN
Projeto Siren - Práticas Extensionistas


## Simulador acadêmico

A landing page inclui uma seção **Simulador** que incorpora o protótipo localizado em `simulador/index.html`.

- `simulador/index.html`: estrutura da demonstração;
- `simulador/styles.css`: visual do app de água, central e contato;
- `simulador/script.js`: lógica de hidratação e acionamento acadêmico;
- `simulador/README.txt`: instruções da demonstração.

Na simulação, o botão comum adiciona 250 ml. O valor `180` funciona somente como código demonstrativo para exibir o alerta na central e no contato de confiança. Nenhum alerta real é enviado.
